# macOS AIPlayer 0.2.1

Файл: `AIPlayer-0.2.1-macOS-arm64.dmg`, 112 956 361 байт (около 113 МБ).

SHA-256: `b24050fa38032caab90990cfcd7eb6f60481547e2e8527a2f4565735a349bb40`.

## Совместимость и установка

macOS 14+ и Apple Silicon (серия M). Эта сборка не предназначена для Intel Mac. Откройте DMG, перетащите AIPlayer в Applications / Программы и запустите оттуда. Модели и настройки находятся отдельно от приложения, в системном каталоге данных; замена приложения их не удаляет. Весов моделей внутри DMG нет.

У приложения ad-hoc-подпись для целостности. Developer ID и нотариальная проверка Apple пока отсутствуют. При загрузке через браузер macOS может блокировать запуск. Если пользователь доверяет файлу, после попытки запуска разрешение для него можно выдать через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». [Официальная инструкция Apple](https://support.apple.com/102445). Защита ОС не отключается.

## Реальная проверка

- Собрано нативно на macOS arm64 из исходников версии 0.2.1, Python 3.12 и PyInstaller.
- `codesign --verify --deep --strict` проходит для исходной .app и для копии из DMG.
- ZIP проверен на целостность; DMG проверен `hdiutil verify`.
- DMG смонтирован read-only, приложение скопировано с сохранением ресурсов и ссылок в отдельный каталог с пробелами и кириллицей, образ отключён.
- Копия из DMG запущена с чистыми настройками: код 0, получен снимок окна 2480×1576.
- Отдельный запуск копии через Launch Services (`open -n -W`): код 0, EXIT 0 в журнале.
- В отдельном профиле открыта синтетическая H.264/AAC-запись: PlayingState, BufferedMedia, позиция более 5 секунд, длительность 18 880 мс, hasVideo=True, пустая ошибка медиадвижка. На снимке видны кадр и готовая расшифровка.
- Во всех трёх сценариях отсутствуют traceback и ошибка загрузки QML; завершение EXIT 0.

Отчёты: `work/qa/macos-0.2.1-installed/`, журнал сборки `work/qa/macos-0.2.1-build.log`. Диагностический параметр --screenshot на macOS может вызывать лишнее FileOpenEvent из аргументов запуска; это известное ограничение диагностического запуска, отмеченное также в VALIDATION.md для 0.1.8. Проверка Launch Services выполнялась без --screenshot.

Проверка не имитирует Gatekeeper на чужой машине после загрузки из интернета; отсутствие Developer ID и нотариальной проверки указано явно. Intel и другие версии macOS в этой проверке не участвовали.

## Повторная сборка

```sh
python build.py
python packaging/build_macos_dmg.py
python packaging/check_macos_startup.py --dmg outputs/AIPlayer-0.2.1-macOS-arm64.dmg --report-root work/mac-check --media path/to/test.mp4
```

Для проверки используйте новый каталог отчёта. Сценарий не заменяет пользовательское приложение в Applications и не меняет его настройки.
