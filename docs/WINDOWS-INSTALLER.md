# Windows-установщик AIPlayer 0.2.1

Исправленная версия: `outputs/AIPlayer-0.2.1-Windows-x64-Setup.exe`.

Размер: 95 951 910 байт. SHA-256:

`40762875496b904db6612ab87fc928b26be4a00078f8ad0a355dba24b3ffba51`

## Исправление запуска

Установщик 0.2.0 успешно устанавливал приложение, однако EXE завершался с кодом 1 до появления окна. Ошибка воспроизведена в Windows run 44035119616. В пакете отсутствовала `Qt6QuickControls2BasicStyleImpl.dll`, необходимая сохранённому QML-плагину Basic/impl. Сборка теперь сохраняет транзитивные Qt-зависимости всех оставленных native-плагинов.

Добавлен стартовый журнал до импорта Qt/ONNX и нативное сообщение Windows при ошибке. Журнал: `%LOCALAPPDATA%\LocalMedia\Player\logs\startup.log`. Старую версию 0.2.0 передавать не следует.

## Установка

Передайте новый EXE. Его можно установить поверх 0.2.0. Каталог установки и AppId сохранены; настройки и модели находятся отдельно. Python и DLL устанавливать отдельно не требуется. Распознавание и Ollama готовятся встроенным онбордингом после запуска.

Установка для текущей учётной записи в `%LOCALAPPDATA%\Programs\AIPlayer`, без прав администратора. Windows 10 22H2 / Windows 11 x64. У EXE пока нет сертификата издателя; Windows может показать предупреждение о неизвестном издателе. Защитные настройки ОС не отключаются.
